# 低代码与后台管理框架选型

这是一份候选项目清单。先按部署方式、权限模型和页面开发方式缩小范围，再用同一个业务样例试用候选框架。

## 候选项目

| 范围 | 项目 |
| --- | --- |
| 若依 | 前后端分离版、微服务版 |
| 若依衍生项目 | RuoYi-Vue-Plus、RuoYi-Vue-Pro |
| 其他候选 | Smart-Admin、JeecgBoot、Guns、EL-Admin、Pig、Lamp Cloud、Erupt、SpringBlade、JeeSite、Snowy |

原笔记中的 `esayadmin` 待核对项目名称和仓库地址。

## 用同一个业务样例验证

1. 建立一个带分页、筛选和新增表单的管理页面，记录哪些步骤可以生成，哪些需要手写。
2. 准备管理员和普通用户两个角色，检查菜单、按钮、后端接口和数据范围的权限控制。
3. 记录本地启动所需服务、部署步骤和二次开发的改动范围，再按团队的部署条件和维护成本比较候选项目。
