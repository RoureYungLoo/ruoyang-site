## 推荐学习路径

### 基础进阶

从原理到实现，系统补齐计算机基础：

1. [计算机网络](/cs_base/net/) — 协议、分层与网络实践
2. [操作系统](/cs_base/os/) — 进程、内存与 Linux
3. [数据结构](/cs_base/ds/) — 组织和处理数据的方法
4. [算法分析](/cs_base/alg/) — 复杂度、设计与实现

### Java 后端

从语言基础出发，逐步进入框架、数据库和服务基础设施：

1. [Java 基础](/langs/java/) — 语法、类型与面向对象
2. [Spring Framework](/spring/base/) — 容器与应用基础
3. [数据存储](/db/) — MySQL、Redis 与 MongoDB
4. [消息队列](/mq/kafka/) — Kafka 与 RocketMQ

### 面试复习

围绕高频主题快速回顾，并通过场景问题检验理解深度：

1. [Java 面试题](/interviews/java/base) — 集合、并发、JVM 与反射
2. [MySQL 面试题](/interviews/mysql/mysql) — 索引、事务与优化
3. [Redis 面试题](/interviews/redis/redis) — 数据结构、缓存与高可用
4. [场景面试题](/interviews/scenes/) — 综合分析与方案设计
