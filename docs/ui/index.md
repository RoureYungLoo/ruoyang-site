| 工具         | 核心优势                                               | 适合场景                                                  | 主要局限                                      | 学习曲线 |

| **Axure RP** | **复杂交互逻辑**的深度模拟，如条件判断、变量、动态面板 | B端产品、后台系统、需精确演示复杂业务逻辑的项目           | 学习成本高，协作能力弱，与UI设计割裂          | 陡峭     |
