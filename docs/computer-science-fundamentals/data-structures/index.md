# 数据结构学习指南

数据结构决定数据如何组织，也直接影响操作的时间和空间成本。选择结构时，应先明确主要操作，再比较其复杂度、顺序要求和内存开销。

## 核心结构

| 类型 | 擅长的操作 | 常见场景 |
| --- | --- | --- |
| 数组 | 按下标随机访问 | 连续数据、查表 |
| 链表 | 已知位置的插入与删除 | 频繁调整顺序 |
| 栈 | 后进先出 | 调用栈、表达式求值 |
| 队列 | 先进先出 | 任务调度、消息缓冲 |
| 哈希表 | 平均常数时间查找 | 索引、缓存、去重 |
| 树 | 保持层级或有序关系 | 文件目录、数据库索引 |
| 图 | 表达多对多关系 | 路由、依赖、社交关系 |

学习每种结构时，建议同时实现其基本操作，并分析查找、插入、删除和遍历的复杂度。
