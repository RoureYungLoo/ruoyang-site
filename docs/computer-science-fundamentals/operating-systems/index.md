# 操作系统学习指南

操作系统负责管理处理器、内存、存储设备和外设，并为应用程序提供稳定的运行环境。理解操作系统，有助于分析程序性能、并发问题和线上故障。

## 核心主题

- 进程与线程：调度、上下文切换、同步与通信；
- 内存管理：虚拟内存、分页、缓存与内存分配；
- 文件系统：文件、目录、权限、缓冲与持久化；
- I/O：中断、系统调用、阻塞与非阻塞模型；
- 并发控制：锁、信号量、死锁及其预防；
- Linux 实践：环境配置、常用命令和故障排查。
