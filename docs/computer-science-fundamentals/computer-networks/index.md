# 计算机网络学习指南

计算机网络关注设备之间如何可靠、高效地交换数据。学习时可以围绕“数据经过了哪些层、每一层解决什么问题、故障发生在哪一层”建立知识框架。

## 推荐顺序

1. 网络分层：理解 OSI 与 TCP/IP 模型，以及封装和解封装过程。
2. 局域网：掌握 MAC、ARP、交换机和 VLAN。
3. 网络层：掌握 IP 地址、子网、路由和 ICMP。
4. 传输层：比较 TCP 与 UDP，理解连接、可靠传输和拥塞控制。
5. 应用层：学习 DNS、HTTP、TLS 等常用协议。
6. 网络实践：结合抓包、路由表和端口状态进行问题定位。
