# 快速入门

- 组件: 返回HTML标签的JS函数. 组件可以嵌套, React组件名必须符合大驼峰, HTML标签必须全部小写.
- JSX, 基于JavaScript的XML, 标签必须闭合, 标签必须位于同一个父标签
