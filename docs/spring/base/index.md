# Spring Framework 快速入门

Spring Framework 为 Java 应用提供依赖注入、面向切面编程、事务管理和 Web 开发等基础能力。

## 核心概念

- IoC 容器负责创建对象、配置依赖并管理生命周期；
- 依赖注入让组件依赖接口或抽象，降低模块耦合；
- AOP 将日志、事务和权限等横切逻辑从业务代码中分离；
- 声明式事务通过统一边界保证一组数据库操作的一致性；
- Spring MVC 使用控制器、请求映射和参数绑定构建 Web 接口。

学习时建议先掌握 Bean 的创建过程和注入方式，再进入 AOP、事务与 MVC。Spring Boot 在这些能力之上提供了自动配置和更便捷的工程启动方式。
