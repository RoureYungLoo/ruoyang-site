# 关于本站

这里是禄若阳的个人技术知识库，主要记录软件开发、计算机基础和工程实践中的学习过程。

## 内容方向

- 计算机网络、操作系统、数据结构与算法等基础知识；
- Java、C、C++、JavaScript 等编程语言；
- 数据库、消息队列、Web 服务和常用中间件；
- 面试复习、问题排查与项目实践。

本站内容会持续整理。笔记首先服务于理解和复习，也希望能为遇到相同问题的读者提供线索。若发现内容错误，可以通过页面底部的“在 GitHub 上编辑此页面”参与修正。

## 使用建议

初次访问可以从[首页](/)选择知识领域或学习路径；查找具体主题时，可以使用导航栏中的站内搜索。
