## Attributes 和 Properties

HTML标签属性和JS对象属性

浏览器加载页面时, 会将HTML标签attribute转为JS property, 但并不是所有的attribute和property一一对应

非标准的HTML attribute 不会创建 property

一个元素A的标准的attribute对于另一个元素B可能是未知的

```javascript

```

HTML attribute的特点: ①大小写不敏感 ②字符串类型

HTML attribute和JS property 会保持属性同步, 但是有例外:

```javascript
let input = document.querySelector('input');

  // attribute => property
  input.setAttribute('value', 'text');
  alert(input.value); // text

  // 这个操作无效，property => attribute
  input.value = 'newValue';
  alert(input.getAttribute('value')); // text（没有被更新！）
```

- String:  `id="input"`
- boolean:  `checked`
- 对象:  `style="color:red;font-size:120%"`

## 事件监听器

### 注册方式①

通过HTML oneventname attribute 或 onEventName property,

一个事件不能添加多个监听器

```javascript
<p onclick="alert('点击了p标签')">p标签</p>

<p onclick="handler()">p标签</p>

function handler(){}
// 添加
elem.onClick=handler
// 删除
elem.onClick=null
// 
this代表事件源, 发生事件的元素

前者必须带上(),后者必须不能带()
```

### 注册方式②

通过elem.addEventListener('eventName', handlerFunction)

通过elem.addEventListener('eventName', handlerObj)

```javascript
// 添加
elem.addEventListener('eventName', handler1, options)
elem.addEventListener('eventName', handler2, options)
elem.addEventListener('eventName', handler3, options)

// 删除, handler不能写箭头函数
elem.addEventListener('eventName', handler1, options)
elem.addEventListener('eventName', handler2, options)
elem.addEventListener('eventName', handler3, options)

options:{
    once: 单次监听
    capture: 是否采用捕获事件模式
    passive: 被动模式
}
```

### 事件监听器函数

```javascript
  function handleClick(event) {
    console.log(event.target)
  }

div.addEventListener('click', handleClick)
```

### 事件监听器对象

```javascript
  let obj = {
    handleEvent(event) {
      console.log(event)
      switch(event.type) {
        case 'mousedown':
          handleMousedown(event);
          break;
        case 'mouseup':
          handleMouseup(event);
          break;
      }
    }
  }
div.addEventListener('click', obj)
```

# 异步请求

## XMLHTTPRequest

```javascript
  /* XMLHttpRequest */
  let url = "https://mock.apifox.cn/m1/3083103-0-default/emps/list"
  let req = new XMLHttpRequest();
  req.open('get', url, true)
  req.send()
  req.onreadystatechange = () => {
    console.log(req.readyState);
    if (req.readyState === 4) {
      console.log(req.responseText);
    }
  }
```
