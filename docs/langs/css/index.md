# CSS 学习指南

CSS 用来描述网页的视觉表现与布局。本专题将原有长篇笔记拆分为更易阅读和检索的五个部分，建议按顺序学习。

## 学习路径

1. [基础、选择器与文本](./basics.md)：样式表、选择器、颜色、字体、文本和列表。
2. [盒模型](./box-model.md)：尺寸、边框、内外边距、圆角和阴影。
3. [背景、表格与表单](./backgrounds-and-forms.md)：背景效果、精灵图、字体图标、表格和表单美化。
4. [定位与布局](./layout.md)：定位、浮动、Flex、常见页面布局和代码规范。
5. [特性与扩展](./advanced.md)：优先级、层叠、继承、Emmet、渐变、过渡与动画。

## 学习建议

- 先理解层叠、继承和盒模型，再进入复杂布局。
- 阅读示例时在浏览器开发者工具中修改属性，观察布局变化。
- 新项目优先使用 Flex 或 Grid，浮动布局主要用于理解和维护旧代码。
