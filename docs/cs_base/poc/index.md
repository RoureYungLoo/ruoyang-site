# 计算机组成原理学习指南

计算机组成原理连接了程序代码与硬件执行过程。重点不是记忆硬件名词，而是理解一条指令如何被取出、解释和执行，以及数据如何在处理器、内存和外设之间流动。

## 核心主题

1. 数据表示：二进制、补码、浮点数和字符编码。
2. 运算器：算术逻辑运算及其硬件实现。
3. 指令系统：指令格式、寻址方式和执行周期。
4. 处理器：数据通路、控制器、流水线与分支预测。
5. 存储系统：寄存器、缓存、主存和外存的层次结构。
6. 输入输出：中断、DMA 与设备控制。

建议结合汇编代码、缓存命中率和程序性能案例学习，把抽象结构与实际程序行为联系起来。
